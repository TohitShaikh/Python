-----------------------------------------------------------Fundamental Category DataType----------------------------------------------
-------------------------------------------------------------------int---------------------------------------------------------
1)Decimal Number System--------------------------------------------------------

>>> a=100
>>> print(a,type(a)) ---->100 <class 'int'> 
>>> b=50
>>> print(b,type(b)) ---->50 <class 'int'>
>>> c=a+b
>>> print(c,type(c)) ---->150 <class 'int'>

2)Binary Number System---------------------------------------------------------

>>> a=0b101
>>> print(a) ------->5
>>> print(a,type(a)) ----->5 <class 'int'>
>>> a=0B1010
>>> print(a,type(a)) ----->10 <class 'int'>
>>> bin(5) ------>'0b101'
>>> bin(23) ----->'0b10111'

3)Octal Number System-----------------------------------------------------------

>>> a=0o12
>>> print(a,type(a)) ----->10 <class 'int'>
>>> b=0O267
>>> print(b,type(b)) ----->183 <class 'int'>
>>> oct(56) ----->'0o70'
>>> oct(49) ----->'0o61'
>>> c=0o89 -----> SyntaxError: invalid digit '8' in octal literal

-------------------------------------------------------------END-------------------------------------------------------
