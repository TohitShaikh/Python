----------------------------------------------------------------Base Conversion Function--------------------------------------------------------------
---------------------------------------------------
1) bin()
---------------------------------------------------

a)Decimal to Binary
>>> a=15
>>> print(a) ----->15
>>> bin(a) ----->'0b1111'
>>> bin(112) ----->'0b1110000'
>>> bin(50000) ----->'0b1100001101010000'

b)Octal to binary
>>> a=0o123
>>> print(a) ----->83
>>> bin(a) ----->'0b1010011'
>>> bin(0O64) ----->'0b110100'

c)Hexa Decimal to Binary
>>> a=0x12
>>> print(a) ----->18
>>> bin(a) ----->'0b10010'
>>> bin(0XFace) ----->'0b1111101011001110'

---------------------------------------------------
2) oct()
---------------------------------------------------

a)Decimal to Octal
>>> a=12
>>> print(a) ----->12
>>> oct(a) ----->'0o14'
>>> oct(23) ----->'0o27'

b)Binary to Octal
>>> a=0b1010
>>> print(a) ----->10
>>> oct(a) ----->'0o12'
>>> oct(0b101010) ----->'0o52'

c)Hexa Decimal to Octal
>>> a=0x12
>>> print(a) ----->18
>>> oct(a) ----->'0o22'
>>> oct(0xface) ----->'0o175316'

---------------------------------------------------
3) hex()
---------------------------------------------------

a)Decimal to hexadecimal
>>> a=15
>>> print(a) ----->15
>>> hex(a) ----->'0xf'
>>> hex(1140) ----->'0x474'

b)Binary to Hexa decimal
>>> a=0b101010
>>> print(a) ----->42
>>> hex(a) ----->'0x2a'
>>> hex(0b1010100101) ----->'0x2a5'

c)Octal to Hexa decimal
>>> a=0o245l
>>> print(a) ----->165
>>> hex(a) ----->'0xa5'
>>> hex(0o45) ----->'0x25'
