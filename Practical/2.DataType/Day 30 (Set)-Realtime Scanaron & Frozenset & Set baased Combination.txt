Problem to be solved by set function/Solving Real-World Problems with Set Functions
----------------------------------------------------------------------------------------------
Q.Consider The Following?
    set of cricket of player={"Rohit","Kohli","Rossum"}
    set of Tennis of player={"Rossum","Travis","Kinney"}

Q.Solve the following 
	1.Find all the Player Names who are playing all the Games.
	2.Find all the Player Names who are playing Both Cricket an Tennis.
	3.Find all the Player Names who are playing Only Cricket but not Tennis.
	4.Find all the Player Names who are playing Only Tennis but not Cricket.
	5.Find all the Player Names who are playing Playogn Exclusively Cricket and Tennis
-------------------------------------------------------------------------
1.Find all the Player Names who are playing all the Games. ----union()
-------------------------------------------------------------------------
>>> cp={"Rohit","Kohli","Rossum"}
>>> tp={"Rossum","Travis","Kinney"}
>>> print(cp,type(cp)) ------> {'Rossum', 'Rohit', 'Kohli'} <class 'set'>
>>> print(tp,type(tp)) ------> {'Travis', 'Kinney', 'Rossum'} <class 'set'>

>>> allcptp=cp.union(tp)
>>> print(allcptp,type(allcptp)) ------> {'Kinney', 'Rossum', 'Kohli', 'Travis', 'Rohit'} <class 'set'>

------------------------------------------------------------------------------------------
2.Find all the Player Names who are playing Both Cricket an Tennis. -----intersection()
------------------------------------------------------------------------------------------
>>> cp={"Rohit","Kohli","Rossum"}
>>> tp={"Rossum","Travis","Kinney"}
>>> print(cp,type(cp)) ------> {'Kohli', 'Rohit', 'Rossum'} <class 'set'>
>>> print(tp,type(tp)) ------> {'Travis', 'Kinney', 'Rossum'} <class 'set'>

>>> bothcptp=cp.intersection(tp)
>>> print(bothcptp,type(bothcptp)) ------> {'Rossum'} <class 'set'>

---------------------------------------------------------------------------------------------
3.Find all the Player Names who are playing Only Cricket but not Tennis. -----difference()
---------------------------------------------------------------------------------------------
>>> cp={"Rohit","Kohli","Rossum"}
>>> tp={"Rossum","Travis","Kinney"}
>>> print(cp,type(cp)) ------> {'Kohli', 'Rohit', 'Rossum'} <class 'set'>
>>> print(tp,type(tp)) ------> {'Travis', 'Kinney', 'Rossum'} <class 'set'>

>>> onlycp=cp.difference(tp)
>>> print(onlycp,type(onlycp)) ------> {'Rohit', 'Kohli'} <class 'set'>

---------------------------------------------------------------------------------------------
4.Find all the Player Names who are playing Only Tennis but not Cricket. -----difference()
---------------------------------------------------------------------------------------------
>>> cp={"Rohit","Kohli","Rossum"}
>>> tp={"Rossum","Travis","Kinney"}
>>> print(cp,type(cp)) ------> {'Kohli', 'Rohit', 'Rossum'} <class 'set'>
>>> print(tp,type(tp)) ------> {'Travis', 'Kinney', 'Rossum'} <class 'set'>

>>> onlytp=tp.difference(cp)
>>> print(onlytp,type(onlytp)) ------> {'Travis', 'Kinney'} <class 'set'>

---------------------------------------------------------------------------------------------------------------
5.Find all the Player Names who are playing Playogn Exclusively Cricket and Tennis  -----symmetric_difference
---------------------------------------------------------------------------------------------------------------
>>> cp={"Rohit","Kohli","Rossum"}
>>> tp={"Rossum","Travis","Kinney"}
>>> print(cp,type(cp)) ------> {'Kohli', 'Rohit', 'Rossum'} <class 'set'>
>>> print(tp,type(tp)) ------> {'Travis', 'Kinney', 'Rossum'} <class 'set'>
>>>
>>> exclcptp=cp.symmetric_difference(tp)

	2.Find all the Player Names who are playing Both Cricket an Tennis.

-------------------------------------------------------------------------
1.Find all the Player Names who are playing all the Games. 
-------------------------------------------------------------------------
>>> cp={"Rohit","Kohli","Rossum"}
>>> tp={"Rossum","Travis","Kinney"}
>>> print(cp,type(cp)) ------> {'Rossum', 'Rohit', 'Kohli'} <class 'set'>
>>> print(tp,type(tp)) ------> {'Travis', 'Kinney', 'Rossum'} <class 'set'>

>>> allcptp=cp|tp #Bitwise OR Operator
>>> print(allcptp,type(allcptp)) ------> {'Kinney', 'Kohli', 'Travis', 'Rohit', 'Rossum'} <class 'set'>

------------------------------------------------------------------------------------------
2.Find all the Player Names who are playing Both Cricket an Tennis. 
------------------------------------------------------------------------------------------
>>> cp={"Rohit","Kohli","Rossum"}
>>> tp={"Rossum","Travis","Kinney"}
>>> print(cp,type(cp)) ------> {'Kohli', 'Rohit', 'Rossum'} <class 'set'>
>>> print(tp,type(tp)) ------> {'Travis', 'Kinney', 'Rossum'} <class 'set'>

>>> bothcptp=cp&tp #Bitwise And Operator
>>> print(bothcptp,type(bothcptp)) ------> {'Rossum'} <class 'set'>

---------------------------------------------------------------------------------------------
3.Find all the Player Names who are playing Only Cricket but not Tennis. 
---------------------------------------------------------------------------------------------
>>> cp={"Rohit","Kohli","Rossum"}

>>> onlycp=cp-tp #Arthematic Minus Operator
>>> print(onlycp,type(onlycp)) ------> {'Rohit', 'Kohli'} <class 'set'>

---------------------------------------------------------------------------------------------
4.Find all the Player Names who are playing Only Tennis but not Cricket.
