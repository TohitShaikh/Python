Syntax-5 print(Messages cum Values with format specifiers) OR print(Values cum Messages with format specifiers)
----------------------------------------------------------------------------------------------------------------
Uses symbols to denote the type of data being printed.
	%d: Integer data 
	%f: Float (decimal) data 
	%s: String data 

>>> a=10
>>> print(a) -----> 
10
>>> print('Value of a is %d' %a) -----> Value of a is 10
>>> toh=23
>>> print('Value of a is %d' %toh) -----> Value of a is 23

>>> a=2.3
>>> print('Value of a is %f' %a) -----> Value of a is 2.300000
>>> print('Value of a is %0.2f' %a) -----> Value of a is 2.30
>>> print('Value of a is %0.1f' %a) -----> Value of a is 2.3
>>> print('Value of a is %0.0f' %a) -----> Value of a is 2
>>> print('Value of a is %0.39f' %a) -----> Value of a is 2.299999999999999822364316059974953532219
>>> print('Value of a is %0.21f' %a) -----> Value of a is 2.299999999999999822364

>>> sno=10
>>> sname='Tohit'
>>> marks=40.97
>>> # My Number is 10 and my name is Tohit  and marks is 40.79
>>> print('My number is %d and my name is %s and my marks is %0.2f' %(sno,sname,marks))
         -----> My number is 10 and my name is Tohit and my marks is 40.97

>>> a=10
>>> b=2.3
>>> c=a+b
>>> #Sum (10,2.3) is 12.3
>>> print('Sum (%d,%0.1f) is %0.1f' %(a,b,c)) -----> Sum (10,2.3) is 12.3


>>> lst=[10,'rs',23.45]
>>> print('Content of lst{}'.format(lst)) -----> Content of lst[10, 'rs', 23.45]
>>> print('Content of lst{}',lst) -----> Content of lst{} [10, 'rs', 23.45]
>>> print('Content of lst%d' %lst) -----> TypeError: %d format: a real number is required, not list
>>> print('Content of lst%s' %str(lst)) -----> Content of lst[10, 'rs', 23.45]

>>> d1={10:'Python',20:'Java',30:'C'}
>>> print('content of d1 is {}'.format(d1)) -----> content of d1 is {10: 'Python', 20: 'Java', 30: 'C'}
>>> print('content of d1 is %s'%str(d1)) -----> content of d1 is {10: 'Python', 20: 'Java', 30: 'C'}

Syntax-6 print(value,end="Delimeter") # Printing the data in horizontal format
----------------------------------------------------------------------------------------------------------------

>>> r=range(10,16)

>>> for val in range(10,16):
...     print(val)
...

>>> for val in range(10,16):
...     print(val,end=" ")
...

...     print(val,end="--->")
