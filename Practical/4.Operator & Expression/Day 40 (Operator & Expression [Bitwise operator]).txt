Float v/s int cetrainity---------------------------------------------
>>> a=3.4
>>> print(a) ------> 3.4

>>> print("%0.5f" %a) ------> 3.40000
>>> print("%0.10f" %a) ------> 3.4000000000
>>> print("%0.15f" %a) ------> 3.400000000000000
>>> print("%0.20f" %a) ------> 3.39999999999999991118
>>> print("%0.25f" %a) ------> 3.3999999999999999111821580
>>> print("%0.30f" %a) ------> 3.399999999999999911182158029987

>>> a=4
>>> print(a) ------> 4
>>> print("%0.5f" %a) ------> 4.00000
>>> print("%0.10f" %a) ------> 4.0000000000
>>> print("%0.15f" %a) ------> 4.000000000000000
>>> print("%0.20f" %a) ------> 4.00000000000000000000
>>> print("%0.25f" %a) ------> 4.0000000000000000000000000
>>> print("%0.30f" %a) ------> 4.000000000000000000000000000000

-----------------------------------------------------------------Bitwise Left Shift Operator(<<)-----------------------------------------------------------------------
>>> a=10
>>> b=3
>>>
>>> c=a<<b
>>> print(c,type(c)) ------> 80 <class 'int'>

>>> a=3
>>> b=2
>>> c=a<<b
>>> print(c,type(c)) ------> 12 <class 'int'>
>>>
>>> a=40
>>> print(a<<2) ------> 160
>>> print(8<<2) ------> 32
>>> print(2.3<<3) ------> TypeError: unsupported operand type(s) for <<: 'float' and 'int'
>>> print(7<<3) ------> 56
>>> print(4<<0) ------> 4
>>> print(4<<-1) ------> ValueError: negative shift count

-----------------------------------------------------------------Bitwise Right Shift Operator(>>)----------------------------------------------------------------------
>>> a=3
>>> b=2
>>> c=a<<b
>>> print(c,type(c)) ------> 12 <class 'int'>
>>>
>>> a=40
>>> a=10
>>> b=3
>>>
>>> c=a>>b
>>> print(c,type(c)) ------> 1 <class 'int'>
>>> print(30>>4) ------> 1
>>> print(100>>3) ------> 12
>>> print(-46<<2) ------> -184

Special Point--------------------------------------------------
>>> print(-46>>2) ------> -12
>>> print(-16>>4) ------> -1
>>> print(-20>>4) ------> -2
>>> print(40>>3) ------> 5
>>> print(-40>>3) ------> -5
>>> print(-43>>3) ------> -6
>>> print(-100>>3) ------> -13
>>> print(-120>>3) ------> -15
