-------------------------------------------------------------------------Identity Operator--------------------------------------------------------------------------
>>> lst=[10,20,30]
>>> lst1=[10,20,30]
>>> lst2=lst1 #Deep Copy

>>> print(lst1,type(lst1),id(lst1)) -----> [10, 20, 30] <class 'list'> 2079236107136
>>> print(lst2,type(lst2),id(lst2)) -----> [10, 20, 30] <class 'list'> 2079236107136
>>> lst1 is lst2 -----> True
>>> lst1 is not lst2 -----> False

>>> lst1=[10,20,30]
>>> lst2=lst1.copy() #Shallow copy
>>> lst1 is lst2 -----> False
>>> lst1 is not lst2 -----> True

Special Point---------------------------------------------
#Value assigned to the variable using multi line assignment it wiil point to same memory address
#Fundamental Data Type with same data values in multipleobject with multi line assignment contains same memory address
>>> a,b=300,300
>>> print(a,id(a)) -----> 300 2234605815696
>>> print(b,id(b)) -----> 300 2234605815696
>>> a is b -----> True
>>> a is not b -----> False

>>> lst1,lst2=[10,20,30,],[10,20,30]
>>> print(lst1,id(lst1)) -----> [10, 20, 30] 2234606926656
>>> print(lst2,id(lst2)) -----> [10, 20, 30] 2234607217920

Note:#All other than Fundamental Data Type with same data values in multipleobject with multi line assignment contains different memory address
>>> lst1 is lst2 -----> False
>>> lst1 is not lst2 -----> True
